# 빌딩앤리치 단축링크

`links.csv`에 한 줄 추가하면 1~2분 뒤 `https://yerin2497-sudo.github.io/yerin/<slug>` 주소가 생깁니다.

| 칸 | 내용 |
|---|---|
| slug | 짧은 이름. 영문·숫자·`-`·`_`만 (예: `yt-1015`) |
| url | UTM이 붙은 긴 주소 |
| memo | 어디에 쓴 링크인지 메모 (주소에는 안 나옴) |

- 목적지를 바꾸려면 url 칸만 고치면 됩니다. 이미 뿌린 단축링크는 그대로 유지돼요.
- 없는 slug로 들어오면 홈페이지로 보냅니다.
- slug 중복·형식 오류가 있으면 배포가 멈추고 Actions 탭에 몇 번째 줄이 문제인지 나옵니다.
